# 🌟 Krishna Hawaldar - Personal Portfolio

A modern, responsive personal portfolio website showcasing my full-stack development skills, projects, certifications, and experience.

## ✨ Features

- **Dynamic Interactive UI**: Smooth animations, particle background canvas, and dynamic typing effect.
- **Modern Responsive Design**: Fully responsive across mobile, tablet, and desktop displays.
- **Sections**:
  - **About Me**: Professional summary and journey.
  - **Skills & Tech Stack**: Interactive skill indicators and technologies.
  - **Certifications**: Verified certificates (IBM C++, Java, JavaScript).
  - **Contact**: Direct communication form and details.

## 🛠️ Tech Stack

- **HTML5** & semantic markup
- **CSS3** (Custom properties, Flexbox, Grid, Glassmorphism, animations)
- **Vanilla JavaScript** (Particles canvas, smooth scrolling, interactive UI)

## 🚀 Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Krishnahawaldar/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your favorite web browser (or use VS Code Live Server).
